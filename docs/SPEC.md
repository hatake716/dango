## 1. 目的と背景

Android標準のファイルアプリは、階層の把握・プレビュー・複数選択操作・ネットワーク接続の面で使いづらい。
本アプリ **dango** は **macOS Finderの見た目・操作感・アニメーション** をAndroid上で再現しつつ、ファイラーとして必要な機能を一通り備えることを目的とする。

### 1.1 主要ターゲット

- 端末: Google Pixel 10a（Android 16）を主要検証端末とする
- 対応範囲: Android 11（API 30）以上。タブレット・横画面でもレイアウトが崩れないこと
- 配布: 当面は GitHub Releases の APK 配布（Play ストア審査を前提としない）

### 1.2 スコープ外（v1では扱わない）

- クラウドストレージ（Google Drive / Dropbox 等）の直接連携
- ルート領域（/system, /data 等）へのアクセス
- iCloud的な同期機能、タグの端末間同期

## 3. ストレージアクセス方針

「ユーザー権限で閲覧できるフォルダ」を最大限表示するため、2段階の権限モデルを採用する。
**v0.2確定: フルアクセスモードを標準とし、通常モードはフォールバックとする。**

### フルアクセスモード（標準）

- 初回起動時のオンボーディングで `MANAGE_EXTERNAL_STORAGE` を **推奨** として要求し、「なぜ必要か」を説明する
- 許可後は `/storage/emulated/0` 配下を `java.io.File` で直接操作

### 通常モード（フォールバック）

- フルアクセスが拒否された場合でもアプリは通常モードで動作を継続する
- `READ_MEDIA_IMAGES / VIDEO / AUDIO` で MediaStore 経由の一覧
- SAF（`ACTION_OPEN_DOCUMENT_TREE`）でユーザーが選択したツリーへの永続アクセス
- SDカード・USB OTG も SAF 経由で扱う
- 設定画面からいつでもフルアクセスへ昇格できる

内部的には両者を `FileSystemProvider` インターフェースで抽象化し、UI層はどちらのモードかを意識しない（§8参照）。

表示対象のルート（Finderの「場所」に相当）:

- 内部ストレージ
- SDカード / USB ドライブ（マウント検出は `StorageManager.storageVolumes`）
- Android/data, Android/obb（Android 11+ はアクセス不可のため、グレー表示＋理由をツールチップ表示）
- ネットワーク接続先（§7）
- ゴミ箱（アプリ内実装。§6.6）

## 4. 画面構成（Finder模倣）

### 4.1 レイアウト

```
┌──────────────────────────────────────────────┐
│ ツールバー  ◀ ▶  [フォルダ名]   ⊞ ≡ ▥ ▤  ⌕  ⋯ │
├────────┬─────────────────────────────────────┤
│サイドバー│  コンテンツ領域                      │
│ よく使う │  (アイコン / リスト / カラム / ギャラリー) │
│ 場所    │                                     │
│ ネットワーク│                                  │
│ タグ    │                                     │
├────────┴─────────────────────────────────────┤
│ パスバー  内部ストレージ › Download › 2026        │
├──────────────────────────────────────────────┤
│ ステータスバー  12項目, 48.2 GB 空き            │
└──────────────────────────────────────────────┘
```

- 縦持ちスマホ: サイドバーはデフォルト非表示。左端スワイプ or ツールバー左のボタンでスライドイン（Finderの ⌘⌥S 相当）
- 横持ち / 幅600dp以上: サイドバーを常時表示（幅 220dp、ドラッグで 180〜320dp に可変）
- ウィンドウ角丸・薄いボーダー・半透明ツールバー（Compose の `Modifier.blur` は負荷が高いため、擬似的に低アルファのサーフェス色で代替）

### 4.2 ツールバー

| 要素 | 動作 |
|---|---|
| ◀ ▶ | 履歴の戻る/進む。長押しで履歴リスト |
| タイトル | 現在のフォルダ名。タップでパス全体をポップアップ（Finderのタイトル⌘クリック相当） |
| 表示切替 | アイコン / リスト / カラム / ギャラリー（セグメンテッドコントロール） |
| 並べ替え | 名前・種類・サイズ・変更日・追加日・タグ、昇順/降順、「フォルダを常に先頭」 |
| 検索 | 現在フォルダ / このデバイス全体 のトグル付き検索フィールド |
| ⋯ | 新規フォルダ、情報を見る、表示オプション、隠しファイル表示、圧縮、接続 等 |

### 4.3 サイドバー

- **よく使う項目**: ダウンロード、書類（Documents）、画像、動画、音楽、ユーザー追加のフォルダ。長押しドラッグで並べ替え、スワイプで削除
- **場所**: 内部ストレージ、外部ボリューム、ゴミ箱。取り外し可能ボリュームには ⏏ アイコン
- **ネットワーク**: 保存済み接続の一覧。未接続はグレー、接続中はスピナー
- **タグ**: 色付きドット + タグ名。タップでタグ検索
- 各アイテムへのドラッグ&ドロップでコピー/移動を受け付ける

### 4.4 表示モード

| モード | 仕様 |
|---|---|
| アイコン | グリッド。サムネイル + ファイル名（2行省略）。ピンチでアイコンサイズ 48〜256dp を連続変更（Finderのスライダー相当） |
| リスト | 名前 / 変更日 / サイズ / 種類 の列。列ヘッダタップで並べ替え、ヘッダ長押しで列の表示切替。フォルダは ▸ で展開可能（Finderの三角展開） |
| カラム | 横スクロールする複数ペイン。選択するたびに右に列が追加され、末尾に選択項目のプレビュー列を表示。**幅600dp未満（縦持ち）では2列固定＋横スワイプで移動（v0.2確定）** |
| ギャラリー | 上部に大きなプレビュー、下部にサムネイルのフィルムストリップ。画像・動画フォルダで自動提案 |

表示モードと並べ替えはフォルダごとに記憶する（Finderの `.DS_Store` 相当。Room に保存し、ファイルシステムには書き込まない）。

### 4.5 パスバー / ステータスバー

- パスバー: 各要素タップでそのフォルダへ移動。長押しで「パスをコピー」。パスバーへのドロップでその階層に移動
- ステータスバー: `N項目選択 / M項目, 空き容量`。転送中は進捗バーに切り替わる

## 5. アニメーション仕様

Finderの動きを再現するため、以下を必須とする。すべて MotionScheme の設定値で一括管理し、ユーザーの「アニメーションを減らす」（`Settings.Global.ANIMATOR_DURATION_SCALE`）を尊重する。

| 場面 | 動き | パラメータ |
|---|---|---|
| フォルダを開く | 新フォルダの内容がわずかに拡大（0.96→1.0）しながらフェードイン、旧内容は縮小フェードアウト | 200ms, EaseOutCubic |
| 戻る | 上記の逆再生 | 同上 |
| Quick Look 起動 | 選択アイテムのサムネイルからプレビューへ共有要素トランジション（SharedTransitionLayout）。Finder のズームアウト感を再現 | 280ms, spring(dampingRatio 0.8, stiffness Medium) |
| Quick Look 閉じる | 元位置へ縮小。下スワイプでもディスミス可、指に追従 | 同上 |
| 選択 | 背景色が 80ms でフェードイン、アイコン下に薄いハイライト | |
| 並べ替え / 表示切替 | 各アイテムが新しい位置へ移動（animateItemPlacement / animateItem） | 250ms |
| リストのフォルダ展開 | ▸ が 90° 回転、子要素が高さアニメーションで出現 | 180ms |
| サイドバー開閉 | 左からスライド。コンテンツ側は押し出されず重なる（縦持ち） | 220ms |
| カラム追加 | 右端に新列がスライドイン + 自動スクロール | 200ms |
| ファイル削除 | ゴミ箱アイコンへ吸い込まれる縮小移動 | 300ms |
| コピー完了 | 貼り付け先アイテムが一瞬強調（scale 1.0→1.05→1.0） | 250ms |
| ドラッグ | ドラッグ元は半透明、ドロップ先フォルダは青枠でハイライト、有効な場合はアイコンが軽くバウンス | |
| ライト/ダーク切替 | 全面クロスフェード | 300ms |
| アイコンサイズ変更 | ピンチ中はリアルタイム追従、離した後にグリッド整列アニメ | |
| ダブルタップ拡大（画像プレビュー） | タップ位置を中心にズーム | 250ms |

## 6. 機能仕様

### 6.1 ナビゲーション

- タップ: 選択。ダブルタップ / 選択中に再タップ: 開く（設定で「シングルタップで開く」に変更可）
- 戻る/進む履歴（最大 50）
- 「上の階層へ」ジェスチャー: パスバーの親要素タップ、または2本指で下スワイプ
- 最近使ったフォルダ（直近 20）、最近使ったファイル（直近 50）

### 6.2 選択

- 長押しで選択モード開始。ドラッグでラバーバンド選択（アイコン表示）
- すべて選択 / 選択解除 / 選択の反転
- 選択中はボトムにアクションバー: 開く、共有、コピー、移動、複製、リネーム、圧縮、削除、情報、その他

### 6.3 ファイル操作

| 操作 | 仕様 |
|---|---|
| 新規フォルダ | 「名称未設定フォルダ」を作成し、即座にインライン編集状態にする。重複時は連番付与 |
| 新規ファイル | テキストファイル（.txt / .md）の空ファイル作成 |
| リネーム | インライン編集。拡張子を除いた部分を初期選択。複数選択時は一括リネーム（連番・検索置換・接頭辞/接尾辞） |
| コピー / ペースト | 内部クリップボードに保持（複数回ペースト可）。同名衝突時は「両方残す（連番）/ 置き換え / スキップ」を選択、「以降すべてに適用」チェックあり |
| 移動 | 「ここに移動」ボタン、またはドラッグ&ドロップ。同一ボリューム内は rename で高速化 |
| 複製 | 同フォルダに「〜のコピー」を作成 |
| 削除 | ゴミ箱へ移動（§6.6）。ゴミ箱内 or 「すぐに削除」で完全削除。完全削除は確認ダイアログ必須 |
| 情報を見る | 名前、種類、サイズ（フォルダは非同期集計）、場所、作成/変更日、権限、MD5/SHA-256（オンデマンド計算）、画像ならEXIF、動画ならコーデック・解像度・長さ、タグ、コメント |
| 共有 / 別のアプリで開く | ACTION_SEND / ACTION_VIEW（FileProvider 経由） |
| ショートカット | ホーム画面にフォルダのショートカット追加 |
| 隠しファイル | `.` 始まりを既定で非表示。トグルで表示 |
| お気に入り | サイドバーへ追加 |
| タグ | Finder同様の7色 + ユーザー定義。Room に保存（拡張属性は Android で非対応のため） |

### 6.4 圧縮・解凍

**解凍（必須）**

- 対応: zip（AES / ZipCrypto 暗号化対応）、tar, tar.gz/tgz, tar.bz2, tar.xz, tar.zst, gz, bz2, xz, 7z（暗号化対応）、rar（**読み取りのみ。rar の作成は非対応（v0.2確定・仕様）**、rar5対応）
- 動作: アーカイブをタップ → 既定は「同名フォルダに展開」。長押しメニューで「ここに展開」「展開先を選択」「内容を表示（展開せず閲覧）」
- 文字化け対策: zip のエントリ名エンコーディングを自動判定（UTF-8 → Shift_JIS → CP437 の順で試行）。ユーザーが明示指定も可
- 安全性: Zip Slip 対策（展開先外へのパスは拒否）、展開後サイズの事前見積もりと空き容量チェック、シンボリックリンクは無視
- 進捗: Foreground Service で通知に進捗表示。キャンセル可
- アーカイブ内ブラウズ: 展開せずに中身をフォルダのように閲覧し、個別ファイルのみ抽出・プレビュー可能

**圧縮**

- 出力形式: zip（既定）、tar.gz、7z（**rar は出力不可（v0.2確定・仕様）**）
- オプション: パスワード、圧縮レベル、「圧縮後に元を削除」
- Finder同様、単一選択なら `<名前>.zip`、複数なら `アーカイブ.zip`

### 6.5 プレビュー（Quick Look）

選択中にスペースキー相当として **2本指タップ** または アクションバーの「プレビュー」で起動。ファイルを直接タップした場合も、対応形式なら Quick Look を開く（設定で外部アプリ優先に変更可）。

| 種別 | 対応形式 | 機能 |
|---|---|---|
| 画像 | JPEG, PNG, WebP, GIF（アニメ）, HEIF/HEIC, AVIF, BMP, SVG | ピンチズーム、ダブルタップ拡大、左右スワイプで同フォルダ内の前後へ移動、EXIF表示、回転、壁紙に設定 |
| 動画 | MP4, MKV, WebM, MOV, AVI（デバイスコーデック依存） | 再生/一時停止、シーク、倍速、字幕（SRT/ASS 外部ファイル）、PiP |
| 音声 | MP3, AAC, FLAC, OGG, WAV, Opus | 波形サムネイル、アルバムアート、バックグラウンド再生 |
| PDF | PDF | ページ送り（縦スクロール/横スワイプ）、ズーム、サムネイル一覧、ページ指定、テキスト検索（API 35+）、パスワード付きPDF |
| テキスト | txt, md, json, xml, yaml, csv, log, 主要ソースコード（kt, py, js, ts, sh, nix, c, rs, go 等） | シンタックスハイライト、行番号、折り返し切替、文字コード自動判定（UTF-8 / Shift_JIS / EUC-JP）、Markdown はレンダリング表示と生表示の切替、CSV は表形式表示、簡易編集（§6.5.1） |
| フォント | ttf, otf | サンプル文の描画 |
| アーカイブ | §6.4 の全形式 | エントリ一覧ツリー |
| APK | apk | アイコン、パッケージ名、バージョン、権限一覧、インストールボタン |
| その他 | | アイコン + メタ情報。「別のアプリで開く」 |

- 2MB 以上のテキスト・10万行以上は先頭部分のみ読み込み、「すべて読み込む」で継続
- プレビュー内の上部に「別のアプリで開く」「共有」「情報」ボタン
- サムネイルはディスクキャッシュ（最大 512MB、LRU）。動画は Media3 の MediaMetadataRetriever でフレーム抽出

#### 6.5.1 テキスト簡易編集（v0.2確定・v1に含める）

- テキストプレビューから「編集」でインライン編集モードに切り替え
- 取り消し / やり直し（アプリ内アンドゥスタック）
- 検索・置換（1件ずつ / すべて置換）
- 改行コードの選択（LF / CRLF。既存ファイルの改行コードを自動検出して既定値にする）
- 文字コードは読み込み時の判定結果で保存（変更は v1 ではスコープ外）
- **2MB 超のファイルは読み取り専用**（編集モードに入れない。理由をスナックバーで表示）
- 保存は確認ダイアログ付き。一時ファイルへ書き込み後に rename する（途中クラッシュで元ファイルを壊さない）
- 編集中の離脱（戻る操作）は「破棄 / 保存 / キャンセル」の3択

### 6.6 ゴミ箱

- `<内部ストレージ>/.Trash-<uid>/` をアプリ管理領域として使用（他ファイラーからは隠しフォルダに見える）
- 元パスと削除日時を Room に記録。「元に戻す」「ゴミ箱を空にする」「30日で自動削除」（設定可）
- ネットワークドライブ上の削除は、プロトコルがサポートする場合のみゴミ箱を使用し、非対応なら即時削除を警告

### 6.7 検索

- インクリメンタル検索。デフォルトは現在フォルダ以下、切替で内部ストレージ全体
- フィルタ: 種類（画像/動画/PDF/文書/圧縮/その他）、サイズ範囲、更新日範囲、タグ
- 全体検索は MediaStore インデックス優先、それ以外は非同期走査（結果を逐次表示）
- 検索条件を「スマートフォルダ」としてサイドバーに保存可能

### 6.8 ストレージ管理

- 「情報を見る」相当でボリュームの使用量を円グラフ表示
- 大きなファイル一覧（上位 100）、重複ファイル検出（サイズ一致 → ハッシュ照合）

## 7. ネットワークドライブ

### 7.1 対応プロトコル

| プロトコル | ライブラリ | 備考 |
|---|---|---|
| SMB2 / SMB3 | smbj | Windows共有、NAS、Samba。**SMB1 は非対応（v0.2確定・仕様として明記）** |
| SFTP | sshj | パスワード / 秘密鍵（OpenSSH形式、パスフレーズ対応）。既知ホスト検証あり |
| WebDAV / WebDAVs | sardine | Nextcloud 等 |
| FTP / FTPS | Commons Net | 平文FTPは警告表示 |

### 7.2 接続管理

- サイドバー「ネットワーク」→「接続を追加」で以下を入力: 表示名、プロトコル、ホスト、ポート、共有名/パス、認証方式、ユーザー名、パスワード or 秘密鍵、「起動時に自動接続」
- サーバ検出: mDNS/DNS-SD（`_smb._tcp`, `_sftp-ssh._tcp`, `_webdav._tcp`）と NetBIOS ブロードキャストで LAN 上のサーバを一覧表示
- 資格情報は Keystore で暗号化して保存。「パスワードを保存しない」オプションあり
- 接続テストボタン
- Tailscale 等の VPN 経由アクセスを想定し、ホスト名に MagicDNS 名を受け付ける

### 7.3 動作仕様

- ネットワーク上のフォルダも通常のフォルダと同じ UI で表示（表示モード、Quick Look、ドラッグ&ドロップ、圧縮/解凍すべて利用可）
- 一覧はキャッシュし、再訪時はキャッシュ表示 → バックグラウンド更新
- ファイルのプレビュー・外部アプリで開く場合はアプリ専用キャッシュに一時ダウンロード（LRU 1GB）。外部アプリに渡す際は FileProvider 経由
- ネットワーク ↔ ローカル、ネットワーク ↔ ネットワークのコピーは WorkManager で実行。再開可能（レジューム対応プロトコルのみ）
- 切断時の挙動: 操作中のダイアログにエラー表示、サイドバーのアイコンがグレーに。再接続ボタン
- モバイルデータ時の転送は既定で確認ダイアログ

## 8. アーキテクチャ

### 8.1 レイヤ構成

```
ui/            Compose 画面、ViewModel、テーマ、アニメーション
domain/        UseCase（CopyFiles, ExtractArchive, ...）、モデル
data/
  fs/          FileSystemProvider 実装
    local/     File ベース（フルアクセス）、SAF ベース、MediaStore
    network/   Smb, Sftp, WebDav, Ftp
    archive/   アーカイブ内を仮想FSとして提供
    trash/     ゴミ箱
  db/          Room（Bookmark, Connection, Tag, FolderViewSetting, Recent, TrashEntry）
  cache/       サムネイル、ネットワークファイルキャッシュ
  prefs/       DataStore（テーマ、表示設定）
service/       転送・解凍用 Foreground Service / Worker
```

### 8.2 FileSystemProvider インターフェース（骨子）

```kotlin
interface FileSystemProvider {
    val scheme: String                       // "file", "saf", "smb", "sftp", ...
    suspend fun list(path: FsPath): Flow<FsEntry>
    suspend fun stat(path: FsPath): FsEntry
    suspend fun mkdir(path: FsPath)
    suspend fun rename(from: FsPath, to: FsPath)
    suspend fun delete(path: FsPath, recursive: Boolean)
    suspend fun openRead(path: FsPath): Source     // okio
    suspend fun openWrite(path: FsPath, append: Boolean): Sink
    suspend fun copy(from: FsPath, to: FsPath, progress: ProgressSink): Boolean  // サーバ側コピー可なら true
    fun capabilities(): Set<Capability>            // RENAME, SERVER_SIDE_COPY, TRASH, RESUME, XATTR ...
}
```

パスは `FsPath(scheme, authority, segments)` で統一し、UI はスキームを意識しない。異なる Provider 間の転送は `openRead → openWrite` のストリームコピーで汎用化する。

### 8.3 状態管理

- 画面状態は `StateFlow<BrowserUiState>`（現在パス、エントリ一覧、選択集合、表示モード、ソート、ローディング）
- 長時間処理は `TransferManager` が一元管理し、UI はそこから進捗を購読する（ステータスバー・通知・転送一覧画面）

## 12. 非機能要件

- 1万件のフォルダ一覧を 500ms 以内に初期表示（ページング・仮想化）
- サムネイル生成はバックグラウンドで、スクロール停止後に優先度を上げる
- 100MB ファイルのローカルコピーはOS標準と同等以上の速度（`FileChannel.transferTo` / sendfile 利用）
- メモリ: 大きな画像は `BitmapFactory` の `inSampleSize` でダウンサンプリング、PDF はページ単位で解放
- アクセシビリティ: TalkBack 対応、コントラスト比 4.5:1 以上、最小タップ領域 48dp
- 多言語: 日本語（主）/ 英語。文字列はすべてリソース化
- オフライン: ローカル操作はネットワーク不要

## 13. テスト方針

- 単体: FileSystemProvider 各実装、名前衝突ロジック、Zip Slip 検証、エンコーディング判定
- 統合: Robolectric で SAF / MediaStore の振る舞い、Room マイグレーション
- ネットワーク: Docker（Samba, OpenSSH, Nextcloud, vsftpd）を CI で立ち上げて E2E
- UI: Compose テスト + スクリーンショットテスト（ライト/ダーク × 縦/横）
- 実機: Pixel 10a で毎マイルストーン確認。アニメーションのフレーム落ちは Perfetto で計測
