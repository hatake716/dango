### 2026-08-31 — D&D 修正: 全アイテムを長押しドラッグ可能に

- 症状: ファイル・フォルダの長押しドラッグが始まらない（選択操作になるだけ）
- 真因は 2 段:
  1. `combinedClickable` の `onLongClick` は発火後 `consumeUntilUp()` で全イベントを消費し、
     同居する `dragAndDropSource` の検出器が動けない
  2. それを除いても、新 API `dragAndDropSource(transferData)` の既定開始検出
     `detectTapGestures` は**未消費の down** が必須で、同じアイテムの `combinedClickable` が
     Main パス（内側優先）で先に down を consume するため一度も発火しない（foundation 1.9.3 の
     ソースで確認。検出器の差し替え口は非公開 TODO）
- 対処（DndSupport.kt）:
  - `entryDragSource` をカスタム検出を書けるレガシー API `dragAndDropSource(block)` に変更し、
    `awaitFirstDown(requireUnconsumed = false)` + `awaitLongPressOrCancellation` で開始。
    レガシー実装はハンドラの初回ラムダを保持し続けるため `rememberUpdatedState` で最新の
    transferKeys を参照（複数選択ドラッグの鮮度に必須）
  - `longPressObserver`（消費しない長押し観測）を追加し、IconGridView / FileListView の
    `onLongClick` を置換（ハプティクス付き）。ドラッグ源はリネーム中以外は常時装着
  - `onEntryLongPress` は「未選択なら選択に追加、選択済みなら維持」に変更
- 教訓: エミュレータにリリース署名版が残っていると `install -r` が
  INSTALL_FAILED_UPDATE_INCOMPATIBLE で失敗し続ける（テスト前に `uninstall` する）
- エミュレータ E2E で確認: グリッド未選択ドラッグ / グリッド複数選択ドラッグ（2件同時移動）/
  リスト表示ドラッグ / タップ・ダブルタップの通常動作

**レビュー（同日）**: 3レンズ×敵対的検証のマルチエージェントレビューで 9 件を確認し、以下を修正:

- [high] ドラッグ不可の文脈（ゴミ箱・ネットワーク・アーカイブ）ではドラッグ開始のタッチ
  キャンセルが起きず、長押し→離すで onClick が発火し選択が即解除される回帰
  → ドラッグ可否（dragKeysFor ≠ null）で切り替え: 可なら longPressObserver + ドラッグ源、
  不可なら従来どおり combinedClickable の onLongClick でクリックを飲み込む
- [medium] 選択モード中に未選択アイテムを長押しドラッグすると、ペイロードがコンポジション時の
  古い selection で確定し「表示は3件選択なのに1件しか運ばれない」
  → dragKeysFor を viewModel.state.value（最新値）から計算し、未選択アイテムは
  「selection + 自分」を運ぶ（onEntryLongPress とどちらが先でも同じ結果）
- [low] リストの展開シェブロン長押しが選択モード入りを誘発 / マウス右ボタン静止長押しで
  選択+ドラッグ+メニューが同時成立
  → 観測系を combinedClickable より内側に移し awaitFirstDown(requireUnconsumed=true) に。
  シェブロンや右クリック（Initial パスで消費済み）の down からは発火しなくなる
- [low] dragKeysFor が isRestricted を見ず、制限フォルダのドラッグが無言で空振り
  → 制限エントリはドラッグ自体を開始しない
- [low] ギャラリーで複数選択から個別解除する手段が消滅（タップは selectOnly のため）
  → ストリップ長押しをトグル版 onEntryLongPressToggle に配線
- [low] longPressObserver が初回ラムダを保持し続ける → rememberUpdatedState 化
- SPEC §5 の「ドロップ先アイコンが軽くバウンス」をグリッド/リストに実装（青枠に加えて）
- カラム/ギャラリーの D&D・長押し選択の対象範囲は SPEC §15 #10 に確認事項として追記

**副産物の既存バグ修正**: 起動直後にビュー設定（リスト表示等）が既定のアイコン表示へ
巻き戻ることがあった。load() が古い state スナップショットを suspend（タグ読込）後に
書き戻す lost update が原因で、設定コレクタの反映を上書きしていた。書き込みを最新値からの
copy に変更。同値書き込みでは DataStore が再 emit しないため一度戻ると復旧しない、
「ビュー切替ボタンが効かない」ように見える症状だった

修正後のエミュレータ E2E 再確認: グリッド未選択ドラッグ / 選択+未選択まとめてドラッグ
（2件移動）/ シェブロン長押しで選択モードに入らない / ビュー切替の双方向動作 /
リスト表示ドラッグ。実機インストールは端末再接続待ち

### 2026-08-30 — M4 + M5 + M6 実装（v1.0.0）

**M4（ネットワークドライブ。SPEC §7）**

- SMB2/3（smbj）・SFTP（sshj）・WebDAV（sardine-android）・FTP（commons-net）の
  FileSystemProvider 実装。接続ごとにセッションをキャッシュし、切断時は破棄→再接続
- サイドバー「ネットワーク」: 保存済み接続一覧＋「接続を追加…」。長押し/右クリックで編集・削除
- 接続ダイアログ（表示名・プロトコル・ホスト・ポート・共有名/パス・ユーザー名・パスワード・
  保存有無）＋接続テスト
- 資格情報は EncryptedSharedPreferences（Keystore）。「保存しない」はセッション内のみ保持
- SSH ホスト鍵は TOFU（初回記録→以後一致検証。変化時は接続拒否）
- ネットワーク⇔ローカルのコピー/移動: FileSystemProvider の openRead→openWrite
  ストリームコピーに一般化（衝突ダイアログ・進捗・キャンセル共通）
- プレビューはアプリ専用キャッシュ（上限 1GB、古いものから削除）へ一時ダウンロード→Quick Look
- ネットワーク上の削除はゴミ箱を経由せず確認ダイアログ付きで即時削除（SPEC §6.6）
- 平文 FTP は接続時に警告（SPEC §7.1）

**M5（カラム/ギャラリー・検索・タグ）**

- カラム表示: 祖先チェーンを列で表示、600dp 未満は2列幅＋横スクロール、末尾に選択項目の
  プレビュー列、カラム追加時の自動スクロール（SPEC §4.4, §5）
- ギャラリー表示: 上部プレビュー＋フィルムストリップ
- 検索: ツールバーの検索フィールドでインクリメンタル（300ms デバウンス・500件上限・
  「このフォルダ / デバイス全体」トグル）
- タグ: 7色（SPEC §9 トークン）。右クリックメニューの色ドットでトグル、アイコン/リスト表示に
  ドット表示、サイドバー「タグ」から横断検索。Room 保存・実体消失時は自動掃除

**M6（仕上げ）**

- 設定画面（SPEC §10）: テーマ / Material You 動的カラー（アクセントのみ追従）/
  シングルタップで開く / ゴミ箱自動削除日数（7/30/90）/ キャッシュ消去 / 生体認証ロック / バージョン
- 生体認証ロック: 起動時に端末の BiometricPrompt（生体＋画面ロック資格情報）
- 英語ローカライズ（values-en 全文言）。既定は日本語
- サムネイルの contentDescription 付与などアクセシビリティの初回パス
- versionCode 2 / versionName 1.0.0

**M4〜M6 で意図的に後回しにしたもの**

- mDNS/DNS-SD・NetBIOS のサーバ検出（SPEC §7.2。手動入力で代替）
- SFTP の秘密鍵認証（パスワードのみ。SPEC §7.2）と既知ホストの厳密管理 UI（TOFU のみ）
- FTPS・WebDAV の詳細 TLS 設定、転送のレジューム（SPEC §7.3）
- モバイルデータ時の転送確認ダイアログ（SPEC §7.3）
- ネットワーク上の圧縮/解凍・複製・サムネイル・ドラッグ&ドロップ・検索
- スマートフォルダ・重複ファイル検出・大きなファイル一覧（SPEC §6.7, §6.8）
- ユーザー定義タグ・タグの複数条件検索（7色固定）

### 2026-08-30 — M3 実装＋ドラッグ&ドロップ＋右クリック

**M3（圧縮・解凍・アーカイブ内ブラウズ。SPEC §6.4）**

- 解凍: zip（AES/ZipCrypto、zip4j）、tar / tar.gz / tar.bz2 / tar.xz / tar.zst / gz / bz2 / xz / zst
  （commons-compress + XZ + zstd-jni）、7z（暗号化対応）、rar（読み取りのみ・junrar）
- zip エントリ名の文字コード自動判定（UTF-8 → Shift_JIS → CP437）＋「オプションを指定して展開」で明示指定
- アーカイブを開く＝既定「同名フォルダに展開」、右クリックで「ここに展開」「内容を表示」
- Zip Slip 遮断・展開後サイズの事前見積もりと空き容量チェック・シンボリックリンク無視
- アーカイブ内ブラウズ（仮想フォルダ表示、個別ファイルのプレビュー＝キャッシュ展開、
  「フォルダに書き出す」）、パスワードダイアログ（zip/7z/rar）
- 圧縮: zip（既定・パスワード AES-256・レベル選択）/ tar.gz / 7z、「圧縮後に元を削除」、
  単一は <名前>.zip・複数は アーカイブ.zip
- Quick Look にアーカイブページ（エントリ一覧ツリー）
- 進捗は転送と同じ FG サービス通知＋ステータスバー（展開中/圧縮中）

**ドラッグ&ドロップ（SPEC §6.3, §4.3, §4.5, §5）**

- 選択済みアイテムの長押しドラッグで移動。ドロップ先: フォルダアイテム・サイドバー各項目・
  パスバーの各階層。サイドバーのゴミ箱へのドロップで削除
- ドラッグ元は半透明、ドロップ先は青枠ハイライト。自己・子孫へのドロップは拒否
- マウスドラッグでも動作（プラットフォーム DnD API）

**マウス右クリック**

- エントリ上: 開く/プレビュー/（アーカイブ: 内容を表示・ここに展開・オプション展開）/共有/
  別のアプリで開く/コピー/移動/複製/リネーム/圧縮/ゴミ箱に入れる/情報
- ゴミ箱内: 元に戻す/すぐに削除/情報。アーカイブ内: 開く/フォルダに書き出す
- 何もない場所: 新規フォルダ/新規テキスト/貼り付け/再読み込み

**M3 時点の注記・後回し**

- RAR5 は junrar 未対応のため読み取り不可（SPEC §6.4 の「rar5対応」と乖離 → §15 #8 に確認事項）
- 「展開先を選択」はフォルダピッカー未実装のため後回し（ここに展開/同名フォルダで代替）
- 7z 出力の暗号化は commons-compress 未対応（パスワードは zip のみ。§15 #8 に記載）
- ドラッグの自動スクロール・修飾キーでのコピー切替・ゴミ箱からのドラッグは M5
