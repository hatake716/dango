### 2026-08-30 — M3 実装＋ドラッグ&ドロップ＋右クリック

**M3（圧縮・解凍・アーカイブ内ブラウズ。SPEC §6.4）**

- 解凍: zip（AES/ZipCrypto、zip4j）、tar / tar.gz / tar.bz2 / tar.xz / tar.zst / gz / bz2 / xz / zst
  （commons-compress + XZ + zstd-jni）、7z（暗号化対応）、rar（読み取りのみ・junrar）
- zip エントリ名の文字コード自動判定（UTF-8 → Shift_JIS → CP437）＋「オプションを指定して展開」で明示指定
- アーカイブを開く＝既定「同名フォルダに展開」、右クリックで「ここに展開」「内容を表示」
- Zip Slip 遮断・展開後サイズの事前見積もりと空き容量チェック・シンボリックリンク無視
- アーカイブ内ブラウズ（仮想フォルダ表示、個別ファイルのプレビュー＝キャッシュ展開、
  「フォルダに書き出す」）、パスワードダイアログ（zip/7z/rar）
- 圧縮: zip（既定・パスワード AES-256・レベル選択）/ tar.gz / 7z、「圧縮後に元を削除」、
  単一は <名前>.zip・複数は アーカイブ.zip
- Quick Look にアーカイブページ（エントリ一覧ツリー）
- 進捗は転送と同じ FG サービス通知＋ステータスバー（展開中/圧縮中）

**ドラッグ&ドロップ（SPEC §6.3, §4.3, §4.5, §5）**

- 選択済みアイテムの長押しドラッグで移動。ドロップ先: フォルダアイテム・サイドバー各項目・
  パスバーの各階層。サイドバーのゴミ箱へのドロップで削除
- ドラッグ元は半透明、ドロップ先は青枠ハイライト。自己・子孫へのドロップは拒否
- マウスドラッグでも動作（プラットフォーム DnD API）

**マウス右クリック**

- エントリ上: 開く/プレビュー/（アーカイブ: 内容を表示・ここに展開・オプション展開）/共有/
  別のアプリで開く/コピー/移動/複製/リネーム/圧縮/ゴミ箱に入れる/情報
- ゴミ箱内: 元に戻す/すぐに削除/情報。アーカイブ内: 開く/フォルダに書き出す
- 何もない場所: 新規フォルダ/新規テキスト/貼り付け/再読み込み

**M3 時点の注記・後回し**

- RAR5 は junrar 未対応のため読み取り不可（SPEC §6.4 の「rar5対応」と乖離 → §15 #8 に確認事項）
- 「展開先を選択」はフォルダピッカー未実装のため後回し（ここに展開/同名フォルダで代替）
- 7z 出力の暗号化は commons-compress 未対応（パスワードは zip のみ。§15 #8 に記載）
- ドラッグの自動スクロール・修飾キーでのコピー切替・ゴミ箱からのドラッグは M5

### 2026-08-30 — M1 + M2 実装

**M1（基本操作・選択モード・アニメーション）**

- 選択モード（長押しで開始、すべて選択・反転、ボトムアクションバー 220ms スライド）
- 新規フォルダ / 新規テキスト・Markdown ファイル（作成後すぐインライン編集、重複時連番）
- インラインリネーム（拡張子除き初期選択）、一括リネーム（連番・検索置換・接頭/接尾辞）
- 内部クリップボードでコピー / 移動（複数回ペースト可、クリップボードバー表示）
- 同名衝突ダイアログ（両方残す・置き換え・スキップ＋以降すべてに適用）
- 転送エンジン: 事前スキャンで進捗分母確定、同一ボリューム移動は rename 高速化、
  Foreground Service 通知＋ステータスバー進捗＋キャンセル
- 複製（「〜のコピー」連番）
- ゴミ箱: `.Trash-dango/` + Room 記録、元に戻す / すぐに削除（確認必須）/ 空にする / 30日自動削除、
  削除スナックバーに「元に戻す」
- 共有 / 別のアプリで開く（FileProvider 経由）
- ピンチでアイコンサイズ 48〜256dp、リストの ▸ ツリー展開（90°回転 180ms）
- 貼り付け完了パルス（1.0→1.05→1.0）、削除・並べ替えのアイテムアニメーション
- 縦持ちサイドバーを 220ms スライドのカスタムオーバーレイに変更

**M2（Quick Look・情報ウィンドウ）**

- Quick Look ホスト（フォルダ内ファイルを左右スワイプで前後移動、上部バーに共有・別アプリ・情報）
- 画像: ピンチズーム、ダブルタップ拡大 250ms、等倍時の下スワイプディスミス（指に追従）
- 動画・音声: Media3(ExoPlayer)、シーク・倍速(0.5〜2x)、音声はアートワーク表示
- PDF: PdfRenderer 縦スクロール、ピンチズーム、ページ番号、パスワード付き（Android 15+）
- テキスト: 文字コード自動判定(UTF-8/SJIS/EUC-JP)、行番号、折り返し切替、2MB超は先頭のみ＋
  「すべて読み込む」
- テキスト簡易編集（§6.5.1）: 取り消し/やり直し、検索置換、改行コード選択、2MB超は読み取り専用、
  保存確認＋一時ファイル経由の原子的保存、離脱時の破棄/保存/キャンセル
- 情報ウィンドウ: 種類・サイズ（フォルダは非同期集計）・場所・作成/変更日・アクセス権・
  MD5/SHA-256 オンデマンド計算・画像EXIF・動画/音声メタデータ
- サムネイル: 動画フレーム・GIF・SVG 対応（Coil 3）、ディスクキャッシュ 512MB

**M1/M2 で意図的に後回しにしたもの**

- ドラッグ&ドロップとラバーバンド選択（M5 と合わせて）
- 2本指タップでの Quick Look 起動（アクションバーの「プレビュー」とファイルタップで代替）
- シンタックスハイライト・Markdown レンダリング・CSV 表形式（M6）
- 動画の PiP・字幕、音声のバックグラウンド再生・波形サムネイル（M6）
- 画像ビューアの EXIF 表示（情報ウィンドウで代替）・回転・壁紙に設定（M6）
- PDF のサムネイル一覧・ページ番号指定ジャンプ・テキスト検索（M6。テキスト検索は API 35+）
- テキスト全文読み込みは OOM 回避のため 32MB 上限（超過分は仕様外の巨大ファイルとして注記）
- 真の共有要素トランジション（現状はスケール＋フェードの近似。M6）
- フォント・アーカイブ・APK のプレビュー（M3 以降）
- 列の表示カスタマイズ（M5）
- Hilt 導入（手動 DI の AppContainer で継続。SPEC §15 に確認事項として追記）

### 2026-08-30 — M0 実装

- Kotlin 2.2 + Compose（BOM 2025.10）+ AGP 8.13 のプロジェクト骨格を作成
- Finder 配色トークン（SPEC §9）でライト/ダークテーマ実装。切替はクロスフェード 300ms
- サイドバー（よく使う項目・場所。縦持ちはドロワー、600dp 以上は常時表示）
- アイコン / リスト表示、並べ替え（名前・種類・サイズ・変更日、フォルダ先頭）、隠しファイル切替
- ツールバー（戻る/進む履歴 50 件、表示切替、⋯メニュー）、パスバー、ステータスバー（項目数・空き容量）
- フォルダ開閉のズームアニメーション（200ms EaseOutCubic）、選択ハイライト 80ms
- `FileSystemProvider` 抽象化＋`LocalFileSystemProvider`（フルアクセスモード）
- 権限オンボーディング（フルアクセス標準・通常モードフォールバック、SPEC §3）
- 画像サムネイル（Coil 3、file:// URI）

**M0 で意図的に後回しにしたもの**（仕様からの逸脱ではなく実装順序の調整）:

- Hilt / Room / WorkManager の導入（M1 で基本操作と同時に導入）
- リストの ▸ ツリー展開、列カスタマイズ、ピンチでのアイコンサイズ変更（M1）
- フォルダごとの表示設定記憶（Room 導入後）
- カラム / ギャラリー表示（M5。ボタンはグレーアウトで配置済み）
- 種類ラベルの多言語化（M6）
- 通常モードの MediaStore / SAF プロバイダ本実装（M1。M0 では READ_MEDIA_* の実行時要求＋File 直読みのみ）
- 縦持ちドロワーの開閉 220ms 指定（Material3 標準アニメのまま。M1 でカスタムドロワー化と同時に）
- サイドバーのドラッグリサイズ 180〜320dp（M1）
- SF Symbols 風オリジナル線画アイコン・独自青フォルダ（M5〜M6 のデザインパス。暫定で Material Icons）
